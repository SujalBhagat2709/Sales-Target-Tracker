# Sales Target Tracker

## Overview

Sales Target Tracker is a Python command-line application that helps track monthly sales performance against predefined targets. It calculates achievement percentages, remaining targets, identifies the best-performing month, and provides an overall sales summary.

---

## Features

- Add Monthly Sales Records
- Sales Target Tracking
- Actual Sales Tracking
- Achievement Percentage Calculation
- Remaining Target Calculation
- Monthly Performance Status
- Best Performing Month
- Overall Sales Summary
- Interactive Menu
